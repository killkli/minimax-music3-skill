# MiniMax Music 3 Agent Skill

Generate MiniMax Music 3 audio through a reusable agent skill. The repository includes an automated Colab/Diffusers runner and guidance for an already-running SGLang-Omni service.

- [English documentation](README.en.md)
- [繁體中文文件](README.zh-TW.md)

Install into the default Codex skills directory with `./install.sh`. The skill is named `$minimax-music3`.
